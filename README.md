# Portfolio Website - SmokyDaBear.github.io

This is my personal portfolio website showcasing my projects, skills, and experience. It is built using modern web technologies and designed to provide a smooth and engaging user experience.

View the live site here: [SmokyDaBear.github.io](https://smokydabear.github.io)

- Responsive design for optimal viewing on all devices
- Dark and light mode support
- Smooth scrolling and animations
- Contact form for inquiries

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- React
- Node.js
- Vite
- GitHub Pages for hosting
